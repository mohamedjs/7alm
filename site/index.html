🛍️

متجر وصفحات هبوط

صفحة لكل منتج على /{slug} جاهزة للإعلان، عروض كميات (قطعتين بسعر خاص)، متجر بأقسام وسلة، عربي وإنجليزي ووضع ليلي.

📦

دورة طلب كاملة

State Machine للطلب: انتظار ← موافقة ← تأكيد ← شحن ← تسليم. حجز المخزون من غير تضارب، شحنة على بوسطة لحظة الموافقة، وتحديثات الشحن لحظيًا عن طريق Webhooks.

💬

صندوق رسائل Meta

ماسنجر وإنستجرام دايركت وواتساب Cloud API في شاشة واحدة، مع ربط تلقائي لرقم الواتساب بالعميل وطلباته.

🗨️

الرد على التعليقات

رد علني على تعليق فيسبوك أو إنستجرام، أو رسالة خاصة واحدة للمعلّق (خلال ٧ أيام كما تشترط Meta)، وإخفاء السبام بضغطة.

👥

CRM وكوبونات ومراجعات

عملاء برقم الموبايل وإحصائياتهم، كوبونات بنسبة أو مبلغ أو شحن مجاني، ومراجعات من مشترين حقيقيين فقط برابط موقّع.

✨

استوديو الذكاء الاصطناعي

كامباينات من تليجرام، صور إعلانية وفيديوهات عن طريق OpenRouter، وكلها محفوظة جوه حلم.

مبني على وثائق Meta الرسمية

  • Webhook واحد لكل منتجات Meta مع تحقق X-Hub-Signature-256 على الـ raw body.
  • رد ٢٠٠ في أقل من ٥ ثواني: الـ webhook بيتسجّل في Outbox ويتعالج في الـ worker عن طريق Kafka.
  • منع التكرار في Redis لأن Meta بتعيد الإرسال.
  • نافذة الـ ٢٤ ساعة: رد حر جواها، Human Agent لحد ٧ أيام في ماسنجر وإنستجرام، وقالب معتمد في واتساب.
  • رد خاص واحد بس لكل تعليق، خلال ٧ أيام — مفروض في الـ domain نفسه.
  • ربط Facebook Login for Business: توكن الصفحة طويل المدى، حساب إنستجرام المرتبط، والاشتراك في الـ webhooks تلقائيًا.

شغّله على سيرفرك في ٣ أوامر

VPS واحد عليه Docker ودومين متوجّه عليه. Caddy بيطلع شهادة HTTPS لوحده، والـ migrations بتتنفذ قبل ما الـ api يبدأ، وفيه نسخة احتياطية يومية للداتابيز.

git clone https://github.com/mohamedjs/7alm && cd 7alm
cp .env.production.example .env.production   # domain, secrets, Meta app
docker compose -f docker-compose.prod.yml \
  --env-file .env.production up -d --build

# Meta webhook URL:  https://YOUR_DOMAIN/api/webhooks/meta
